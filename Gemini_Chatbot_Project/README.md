# AI Personal Assistant Comparison Project

## Overview

This project compares:

1. Frontier AI Assistant using Gemini API
2. Open Source Assistant using Qwen2.5 model

Both assistants support:
- Multi-turn conversation
- Context memory
- Assistant behavior
- Safety prompts

---

## Technologies Used

- Python
- Streamlit
- Hugging Face Transformers
- Google Gemini API

---

## Models Used

### Frontier Model
- Gemini 2.5 Flash

### Open Source Model
- Qwen2.5-0.5B-Instruct

---

## Features

- Conversational memory
- System prompts
- Retry handling
- Safety testing
- Evaluation framework
